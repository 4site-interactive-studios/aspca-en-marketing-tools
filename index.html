Set it up in EN

  1. Download the upload files and add them to the ASPCA's EN image library.
  2. On each donation page, paste an email's HTML (listed under Files) into its thank-you email: One-time as the Single Gift message, Monthly and Annual as Recurring Gift messages filtered by frequency.
  3. To build new emails from the same blocks, import the template file and the blocks file in EN Marketing Tools.

    Before the first send

    • The import files carry a placeholder owner and the root folder until we have the ASPCA's EN owner ID and folder ID. Client ID 20014 is inferred from the ASPCA's EN pages.
    • Send a test of each email and check every merge tag: the gift amount's dollar sign, the donation date format, and the address fields.
    • The One-time and Annual emails show their preview text as a line at the top, as the originals did, so inbox previews read it twice. Keep one or the other.
    • Check Outlook, Gmail and Apple Mail on desktop and phone. The emails are light mode only, as the originals were.
